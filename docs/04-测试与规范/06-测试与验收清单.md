## 8. 回归检查顺序（每次改动后）

1. `npm run build` —— TypeScript 与打包；
2. `mvn -q -DskipTests package` × 2 —— 后端编译；
3. `python main.py --dry-run --duration 3` —— 报文格式；
4. 浏览器刷新：控制台 0 error、左右各 5 行、遮罩隐藏；
5. 点「模拟告警」→ 等待恢复 toast；
6. 切换 V2 / V3 与剖切开关，确认无布局溢出；
7. 对照 [07-告警生命周期图](../01-架构与设计图/07-告警生命周期图.svg) 复核状态流转。
