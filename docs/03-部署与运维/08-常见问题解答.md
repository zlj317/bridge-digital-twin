# 08 · 常见问题解答

## A. 启动与构建

### A1. 只想看效果，必须装 Docker / 数据库吗？

不需要。`cd frontend && npm install && npm run dev`，打开 `http://localhost:5173`。
默认 `VITE_DATA_MODE=mock`，内置数据源完整驱动五幕动画、车流、测点、告警与面板。

### A2. `npm install` 后 `npm run build` 报 TypeScript 错误？

本项目构建脚本是 `tsc --noEmit && vite build`，严格模式开启。常见原因：
Node 版本 < 20、依赖未完整安装、`typescript` 版本不符。删除 `node_modules` 与 `package-lock.json` 后重装；
不要跳过 `tsc`，类型契约（`src/types/index.ts`）是前后端一致性的保证。

### A3. Quarkus 编译报 `dependencies.dependency.version is missing`？

Quarkus 3.8 的 REST 扩展名是 `quarkus-resteasy-reactive` / `quarkus-resteasy-reactive-jackson`，
不是 3.9+ 才有的 `quarkus-rest` / `quarkus-rest-jackson`。本仓库两个 `pom.xml` 已使用 3.8 正确名称与 BOM `3.8.6`。

### A4. 后端启动需要 JDK 哪个版本？

JDK 17（Quarkus 3.8 要求）。`java -version` 确认；Maven ≥ 3.9。
端口 8081 / 8082 被占用时先释放或修改 `application.properties` 的 `quarkus.http.port`。

### A5. 修改 `.env` 后刷新浏览器没变化？

`VITE_*` 是 Vite **构建期**变量，需重新 `npm run build` 或重启 `npm run dev`。
Compose 场景还要 `docker compose up -d --build frontend-build` 并重启 `nginx`。

### A6. Docker 首次启动后数据库里没有种子数据？

初始化脚本只在数据卷为空的首次启动执行。若卷已存在，备份数据后 `docker compose down -v` 再 `up -d`，
或手工执行 `deploy/postgres/init/02_seed.sql`。注意 `down -v` 会删除全部卷。

## B. 前端与 3D

### B1. 页面白屏或「初始化失败」？

优先看浏览器控制台。常见原因：浏览器不支持 WebGL2 / 硬件加速被禁用；
`live` 模式下后端与 MQTT 均不可达且降级逻辑异常。换 Chrome/Edge、开启硬件加速、切 `mock` 模式验证。

### B2. 面板只有标题，下面没有数值行？

早期版本曾因 `createPanel` 初始 `rows: []` 且只做增量更新导致。
当前实现中 `update()` 会先检查行数，不一致时先 `render(rows)` 再滚动数值；若仍出现，硬刷新（Ctrl+F5）排除 HMR 缓存。

### B3. 看不到桥塔，只剩一条桥面和扇形拉索？

这是幕四/幕五的「桥底剖切」视角，符合设计。用顶栏视点下拉切「全景鸟瞰」，或点击时间轴第 1 节点回到幕一。

### B4. 相机自动运镜一直抢镜头？

拖拽/滚轮后 `CameraDirector` 会暂停自动运镜 8 秒；8 秒后恢复。若需长时间自由观察，先按空格暂停时间轴。

### B5. 点击桥面没有弹出构件卡？

拾取只命中可拾取层（构件、拉索、车辆、传感器）。点击空白天空/水面不会命中。
可点击桥面梁段、塔柱、拉索或橙色传感器点；命中后会出现 `OutlinePass` 高亮。

### B6. 截图为什么只有 3D，没有左右面板？

「截图」当前导出 WebGL canvas（3D 视口）。合成 DOM 面板需引入 html2canvas 或服务端截图，列为 P1 扩展，
见 [10-开发路线图](../02-开发文档/10-开发路线图.md)。

### B7. 帧率很低怎么办？

系统会在 FPS < 20 时自动关闭 Bloom/后处理。另可：缩小浏览器窗口、关闭其他 WebGL 页面、
降低设备像素比、减少车流密度；车辆超过 300 台时会自动降级几何。

### B8. 数值跳变或不滚动？

`rollNumber` 在动画中断时从当前显示值续接，0.6s 完成。若数据源停止推送，数值会保持不变 —— 检查仿真器或 MQTT。

### B9. favicon 404 报错？

已在 `frontend/index.html` 加入 `<link rel="icon" href="data:," />` 消除噪音；若仍有，清浏览器缓存。

## C. 后端与数据

### C1. 不启动中间件，两个服务能跑吗？

可以。`RuntimeStore` / `RuntimeState` 为默认内存实现；`MqttGateway` 在 broker 不可达时打印告警并启用本地快照定时器。
`/q/health` 中对应组件会显示 DOWN，但服务 `status` 仍为 UP。

### C2. EMQX 连不上会怎样？

三层降级：仿真器 `--dry-run` 打印报文；`svc-shm` 用 `tickLocalSimulation()` 每 2s 生成快照；
前端 MQTT 断连 3 次自动切 `mockSource`。页面顶栏会提示数据模式。

### C3. 告警为什么不立刻弹窗？

按设计必须**连续 3 次超阈值**才触发（防抖），同一测点已有活动告警不重复弹窗；
**连续 3 次回到阈值内**才自动恢复。可用顶栏「模拟告警」按钮在约 6~10 秒内演示完整流程。

### C4. 为什么注入超限后告警又自动恢复？

`BridgeResponseModel.injectOverlimit` 只连发 3 次 58.6 MPa，之后回到正常物理值，
触发 `normalStreak >= debounceDown` 自动恢复，这是 ALM-004 的预期行为。

### C5. 接口返回 404？

检查 Nginx 分流：`/api/v1/bridges/{code}/(metrics|health|inspections)`、`/points`、`/alarms`、`/history/*` 走 8082，
其余走 8081。本机直连 8081/8082 时路径前缀仍为 `/api/v1`。详见 [04-接口文档](../02-开发文档/04-接口文档.md)。

### C6. 统一响应里的 `traceId` 有什么用？

8 位随机标识，用于串联一次请求的前后端日志。P1 接入日志采集后可端到端检索。

### C7. `/history/series` 刚启动就有数据？

是。历史不足时用平滑正弦序列回填，保证回放无空洞；随服务运行逐步替换为真实快照序列。

### C8. 清洗为什么丢弃报文？

校验 `pointCode` 是否存在于 150 个测点、`value` 是否为有限数、时间戳偏差是否 ≤ 5 分钟。
丢弃数在 `/api/v1/system/stats` 的 `rejected` 中累加，服务不会崩溃。

### C9. 为什么 PostgreSQL 里明明有表，服务却还是用内存数据？

`bdt.storage` 默认 `memory`，P0 的设计是有意如此（无中间件即可联调）。
切换 JDBC/TDengine/Redis 实现是 P1 工作，见 [05-数据库设计与数据字典](../02-开发文档/05-数据库设计与数据字典.md) §11。

## D. 部署与运维

### D1. 端口冲突怎么查？

```powershell
netstat -ano | findstr "8081 8082 5432 1883 80"
```

修改 `.env` 中对应端口变量后 `docker compose up -d`；本机直连时改 `application.properties`。

### D2. Windows 下路径或换行有问题？

优先用绝对路径、PowerShell Core；SQL 与 `.env` 保持 UTF-8。
若脚本换行被改成 CRLF 导致容器内异常，用编辑器把挂载的脚本转换为 LF 后重启容器。

### D3. 中文显示为方框？

SVG / Markdown 与前端 CSS 均指定了中文字体栈（`Microsoft YaHei`、`PingFang SC`、`sans-serif`）。
容器日志乱码时设置终端 UTF-8 与 `TZ=Asia/Shanghai`。

### D4. Grafana 没有数据？

确认 Prometheus 目标 UP（`http://localhost:9090/api/v1/targets`），
两个服务的 `/q/metrics` 可访问，且 `deploy/grafana/provisioning` 已挂载。

### D5. 容器反复重启 / OOM？

`docker compose logs <service>` 查看；Compose 已设置内存上限（PG/TDengine 1G、服务 512M 等）。
4C/8G 单机建议分批启动，或减少同时运行的容器。

### D6. 如何确认全链路真的通了？

按顺序：
1. `curl localhost/q/health` → 组件 UP；
2. EMQX Dashboard → Clients 有 `svc-shm-*`、仿真器、前端；
3. `curl localhost:8082/api/v1/system/stats` → `accepted` 增长；
4. 前端顶栏显示「实时链路」，面板数值持续变化；
5. 点击「模拟告警」→ 弹窗 → 恢复 toast。

### D7. 数据如何备份？

见 [07-运维手册](07-运维手册.md) §5：`pg_dump`、Redis `SAVE`、TDengine `taosdump`、MinIO `mc mirror`，以及配置与卷打包。

## E. 范围与规划

### E1. 为什么没有 Blender 导出的 GLB 模型？

需求文档 6.7 描述的 `.blend` 资产不在仓库中。当前由 `frontend/src/three/BridgeBuilder.ts` 按 1.2 参数程序化生成，
并保留 `modelSkeletonCode / modelSolidCode / modelInnerCode` 三套编码契约，后续替换几何来源即可。

### E2. 会做有限元 / 视频 AI / 多桥集群吗？

按需求文档 1.4 明确不做。P1 聚焦生产化（真实 GLB、落库、鉴权、监控），P2 才是多桥、工单、算法扩展，
见 [09-版本路线图](../01-架构与设计图/09-版本路线图.svg) 与 [10-开发路线图](../02-开发文档/10-开发路线图.md)。

### E3. 文档之间怎么导航？

根目录 `README.md` 提供完整文档索引表；每篇文档首尾都有互链；
9 张 SVG 集中在 `docs/01-架构与设计图/`。
