## 1. 总览

全部中间件由 `docker-compose.yml` 定义，配置集中在 `.env.example`（复制为 `.env`）与 `deploy/` 下各子目录。
**不启动任何中间件也能运行前端**（`VITE_DATA_MODE=mock`）；后端服务同样会降级为内存仓储与本地快照。

| 中间件 | 镜像 | 容器名 | 端口 | 默认账号 | 初始化脚本 |
|---|---|---|---|---|---|
| PostgreSQL + PostGIS | `postgis/postgis:15-3.3` | bdt-postgres | 5432 | bridge / bridge123 | `deploy/postgres/init/01_schema.sql`、`02_seed.sql` |
| Redis | `redis:7.2-alpine` | bdt-redis | 6379 | 无密码 | 命令行参数 `--appendonly yes --maxmemory 220mb --maxmemory-policy allkeys-lru` |
| TDengine | `tdengine/tdengine:3.3` | bdt-tdengine | 6030 / 6041 | root / taosdata | `deploy/tdengine/init/01_taos.sql` |
| MinIO | `minio/minio:2025` | bdt-minio | 9000 / 9001 | minioadmin / minioadmin123 | 需手工创建 bucket `bridge-models` |
| EMQX | `emqx/emqx:5.7` | bdt-emqx | 1883 / 8083 / 18083 | admin / admin123 | `deploy/emqx/acl.conf` |
| Nginx | `nginx:1.24` | bdt-nginx | 80 | — | `deploy/nginx/nginx.conf` + `proxy_params.inc` |
| Prometheus | `prom/prometheus` | bdt-prometheus | 9090 | — | `deploy/prometheus/prometheus.yml` |
| Grafana | `grafana/grafana` | bdt-grafana | 3000 | admin / admin123 | `deploy/grafana/provisioning` |

## 2. PostgreSQL / PostGIS

```bash
docker compose up -d postgres
docker exec -it bdt-postgres psql -U bridge -d bridge -c "\dt"
docker exec -it bdt-postgres psql -U bridge -d bridge -c "SELECT count(*) FROM shm_point;"
```

- 扩展：`postgis`、`pg_trgm`（名称模糊索引）。时区设为 `UTC`，业务时间由服务层转换。
- 17 张表、唯一索引 `uk_*`、组合索引与 `COMMENT ON` 注释均在 `01_schema.sql`；字段字典见 [05-数据库设计与数据字典](../02-开发文档/05-数据库设计与数据字典.md)。
- 种子数据 `02_seed.sql` 与 `docs/需求文档/02_seed.sql` 为同一份，包含 1 座桥、72 拉索、42 节段、12 车道、6 视点、5 幕、150 测点等。
- 初始化脚本只在**数据卷为空的首次启动**执行；修改脚本后需 `docker compose down -v` 才会重建（会清空数据，先备份）。
- 健康检查：`pg_isready -U bridge -d bridge`，10s 间隔、10 次重试。

## 3. Redis

```bash
docker compose up -d redis
docker exec -it bdt-redis redis-cli PING          # PONG
docker exec -it bdt-redis redis-cli CONFIG GET maxmemory
```

- 设计用途：`realtime:shm:{bridgeCode}:{pointCode}` 存最新值（TTL 5s）、告警去重集合、快照缓存。
- `maxmemory 220mb` + `allkeys-lru`，AOF 持久化开启，避免重启丢失最新值。
- 当前 P0 服务默认内存仓储，未实际写入 Redis；P1 切换 `bdt.storage=cluster` 后启用。

## 4. TDengine

```bash
docker compose up -d tdengine
curl -u root:taosdata -d "show databases;" http://localhost:6041/rest/sql
curl -u root:taosdata -d "select count(*) from bridge_ts.shm_metric;" http://localhost:6041/rest/sql
```

- 库 `bridge_ts`：`KEEP 365`（保留 365 天）、`DURATION 10`、`PRECISION 'ms'`、`VGROUPS 2`。
- 超级表 `shm_metric(ts, val, quality, source)`，标签 `bridge_code / comp_code / point_code / point_type / unit`；`quality` 0 正常 / 1 可疑 / 2 异常，`source` 0 真实 / 1 仿真。
- 子表：6 个索力测点（`d_pts_c_01` ~ `d_pts_c_06`）+ 5 个聚合指标（`d_pts_str_max` 等），共 11 张。
- 健康检查 `taos -s 'show databases;'`，15s 间隔；REST 端口 6041 供 `/history/*` 查询使用。

## 5. MinIO

```bash
docker compose up -d minio
# Console: http://localhost:9001  (minioadmin / minioadmin123)
docker exec -it bdt-minio mc alias set local http://localhost:9000 minioadmin minioadmin123
docker exec -it bdt-minio mc mb local/bridge-models
docker exec -it bdt-minio mc anonymous set download local/bridge-models
```

- bucket `bridge-models`，存放 GLB / Draco 模型与截图，对象键形如 `glb/girder_shell.glb`。
- `POST /api/v1/models/upload` 当前只登记元数据并返回 `objectKey` 与 `publicUrl` 占位；P1 接入真实上传与预签名 URL。
- 当前几何由 `BridgeBuilder.ts` 程序化生成，不依赖 MinIO 即可运行。

## 6. EMQX

```bash
docker compose up -d emqx
# Dashboard: http://localhost:18083  (admin / admin123)
# TCP 测试（本机装有 mosquitto 客户端时）
mosquitto_sub -h localhost -p 1883 -t "sensor/raw/bridge/+" -v
```

- TCP :1883 供后端与仿真器；WebSocket :8083 经 Nginx `/mqtt` 代理供前端；Dashboard :18083。
- `EMQX_ALLOW_ANONYMOUS=true` 便于本地联调；`acl.conf` 定义主题权限，生产环境应关闭匿名并启用账号认证。
- 主题清单见 [04-接口文档](../02-开发文档/04-接口文档.md) 与 [06-数据链路流程图](../01-架构与设计图/06-数据链路流程图.svg)。

| 主题 | 方向 | QoS | 周期 |
|---|---|---|---|
| `sensor/raw/bridge/{bridgeCode}` | 仿真器 → svc-shm | 1 | 2s |
| `traffic/vehicle/{bridgeCode}` | 仿真器 → 前端 | 0 | 1s |
| `realtime/bridge/{bridgeCode}` | svc-shm → 前端 | 1 | 2s |
| `alarm/bridge/event`、`alarm/bridge/recover` | svc-shm → 前端 | 1 | 事件触发 |
| `sim/bridge/command` | 前端 → 仿真器 / svc-shm | 1 | 按需 |
| `anim/bridge/command` | 前端 → 动画控制 | 0 | 按需 |

- 后端 `MqttGateway` 使用 Paho，`setAutomaticReconnect(true)`；连接失败会打印告警并启用本地快照定时器，服务仍可用。

## 7. Nginx

```bash
docker exec -it bdt-nginx nginx -t
docker compose restart nginx
```

- `location /` → 静态资源（`frontend-dist` 卷），SPA `try_files`。
- `location ~ ^/api/v1/bridges/[^/]+/(metrics|health|inspections)$` → svc-shm；`/api/v1/points|alarms|history|...` → svc-shm；其余 `/api/v1/` → svc-bridge。
- `/mqtt` → `http://emqx:8083/mqtt`，需携带 `proxy_params.inc` 中的 Upgrade / Connection 头。
- `/q/health` → svc-shm（更长前缀优先），其余 `/q/` → svc-bridge。
- 开启 CORS（`*`）、gzip；生产环境应把 `access-control-allow-origin` 收敛到具体域名。

## 8. Prometheus / Grafana

```bash
curl http://localhost:9090/api/v1/targets        # 抓取目标状态
curl http://localhost:8081/q/metrics             # svc-bridge 指标
curl http://localhost:8082/q/metrics             # svc-shm 指标
```

- `deploy/prometheus/prometheus.yml` 定义抓取任务；`deploy/grafana/provisioning` 定义数据源与看板。
- 建议关注：JVM 堆、HTTP 请求延迟与错误率、MQTT 连接状态、FPS（前端上报）、告警产生/恢复速率。

## 10. 不使用 Docker 时的本机安装

| 组件 | 本机安装要点 | 对应配置 |
|---|---|---|
| PostgreSQL 15 + PostGIS 3.3 | 建库 `bridge`、建用户 `bridge`，执行两个 SQL | `bdt.pg.url/user/password` |
| Redis 7 | `redis-server --appendonly yes --maxmemory 220mb --maxmemory-policy allkeys-lru` | `bdt.redis.host` |
| TDengine 3.3 | 安装后启动 `taosd`，执行 `01_taos.sql` | `bdt.tdengine.url` |
| MinIO | `minio server ./data --console-address ":9001"`，创建 bucket | `bdt.minio.endpoint` |
| EMQX 5.7 | 启用 TCP 1883 与 WS 8083，允许匿名（仅开发环境） | `bdt.mqtt.host/port` |
| Nginx | 若无本机 Nginx，可用 `vite.config.ts` 的 dev 代理替代 | `VITE_API_BASE`、`VITE_MQTT_WS_URL` |

> 本机只启动两个 Quarkus 服务 + 前端时，以上组件**均非必需**：服务会降级，前端可用 `live` 或 `mock` 模式。

## 11. 安全建议

1. 生产环境修改 `.env` 中所有默认口令（PG / MinIO / EMQX / Grafana）。
2. 关闭 `EMQX_ALLOW_ANONYMOUS`，为每个服务与仿真器分配账号，收紧 `acl.conf`。
3. PG / Redis 保持仅 `127.0.0.1` 绑定；MinIO / EMQX / Grafana 控制台经网关与防火墙暴露。
4. Nginx CORS 从 `*` 收敛为具体域名，启用 HTTPS；MQTT 使用 WSS。
5. `sys_user.password` 当前为示例字段，P1 实现登录时必须替换为加盐哈希并接入鉴权。
