## 1. 存储分工（实时与历史分离）

| 存储 | 承载 | 理由 |
|---|---|---|
| PostgreSQL 15 + PostGIS 3.3 | 17 张关系表：档案、构件树、几何台账、字典、告警事件、巡检、仿真方案、系统表 | 强一致、可关联、需要 CRUD 与事务 |
| Redis 7.2 | `realtime:shm:*` 最新值（TTL 5s）、告警去重集合、快照缓存 | 高频读写、低延迟 |
| TDengine 3.3 | `bridge_ts.shm_metric` 时序数据与聚合指标子表 | 150 测点 × 2s 写入、时间范围聚合与降采样 |
| MinIO | GLB / Draco 模型、截图、报表 | 大对象、可预签名访问 |

> P0 服务默认内存仓储（`RuntimeStore` / `RuntimeState`），上表为已落库的设计与生产化目标；切换方式见 [10-开发路线图](10-开发路线图.md)。

## 2. 通用约定

| 项 | 约定 |
|---|---|
| 物理主键 | 每张表 `id BIGSERIAL PRIMARY KEY` |
| 业务主键 | 通过 `uk_*` 唯一索引保证（如 `bridge_code`、`comp_code`、`point_code`）；关系图中简写为 `PK 业务码` |
| 软删除 | `is_deleted BOOLEAN DEFAULT false`，唯一索引多为 `WHERE is_deleted = false` 的部分索引 |
| 时间戳 | `create_time` / `update_time` TIMESTAMP DEFAULT NOW()；库时区 `SET TIME ZONE 'UTC'` |
| 扩展字段 | `ext_json JSONB`；几何控制点、相机关键帧、位置等也用 JSONB |
| 坐标系 | SRID=0 平面米制；桥轴沿 X、Y 为高度、Z 为横向，跨中为原点；Y=58 为桥面 |
| 外键主线 | `brg_bridge.bridge_code` → `brg_*` / `sim_plan`；`shm_point.comp_code` → `brg_component.comp_code`；`shm_alarm.point_code` → `shm_point.point_code` |
| 枚举 | 由 CHECK 约束保证，见 §6 |

### 4.6 brg_viewpoint 视点

`vp_code` / `vp_name` / `cam_pos` JSONB / `cam_target` JSONB / `fov`（默认 40） / `sort_no`。
6 个视点：`VP-OVERVIEW` 全景鸟瞰、`VP-DECK` 桥面平视、`VP-UNDER` 桥底剖切、`VP-TOWER` 塔柱特写、`VP-ISO` 等轴测、`VP-SIDE` 桥侧远景。

### 4.7 brg_anim_stage 五幕配置

`stage_code` / `stage_name` / `stage_order` / `start_ms` / `end_ms` / `cam_keyframes` JSONB / `target_comps` JSONB / `auto_play`。
五幕：`ACT-1` 0~4500、`ACT-2` 4500~7500、`ACT-3` 7500~9500、`ACT-4` 9500~12500、`ACT-5` 12500~0（稳态，0 表示持续）。

### 4.8 brg_clip_plan 剖切方案

`plan_code` / `plan_name` / `normal_x/y/z`（默认 -1,0,0）/ `clip_distance`（Plane.constant）/
`show_rebar` / `show_diaphragm` / `show_stiffener` / `edge_color`（`#00E5FF`）/ `is_default`。
两个方案：`CLIP-AXIAL` 沿桥轴、`CLIP-CROSS` 横向剖切。

## 8. TDengine 时序模型

```sql
CREATE DATABASE bridge_ts KEEP 365 DURATION 10 PRECISION 'ms' REPLICA 1 VGROUPS 2;

CREATE STABLE shm_metric (
    ts TIMESTAMP, val DOUBLE, quality TINYINT, source TINYINT
) TAGS (
    bridge_code VARCHAR(64), comp_code VARCHAR(64), point_code VARCHAR(64),
    point_type VARCHAR(32), unit VARCHAR(16)
);
```

- `quality`：0 正常 / 1 可疑 / 2 异常；`source`：0 真实 / 1 仿真。
- 子表 11 张：6 个索力点 `d_pts_c_01` ~ `d_pts_c_06`（图 3 内部透视测点表），5 个聚合指标 `d_pts_str_max` / `d_pts_def_mid` / `d_pts_tmp_avg` / `d_pts_wnd_max` / `d_pts_frq_main`。
- 典型查询：`INTERVAL(1m)` 降采样、`AVG/MAX/MIN` 聚合、`P95` 与超限计数，对应 REST `/history/series` 与 `/history/statistics`。

## 11. 与当前实现的映射

| 设计 | P0 实现 | 替换点 |
|---|---|---|
